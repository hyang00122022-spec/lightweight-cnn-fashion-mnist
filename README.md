# lightweight-cnn-fashion-mnist
Lightweight CNN for Fashion-MNIST classification.3 conv layers with BatchNorm,Dropout,MaxPool.Data augmentation and early stopping fight overfitting.88.63% test accuracy.Trousers,sandals,bags perform well.Similar tops are misclassified due to low-res grayscale.Compact design for edge devices.Future:attention,transfer learning,quantization.
